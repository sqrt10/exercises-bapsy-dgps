
# Exercises for BaPsy DGPs Studieneignungstest

Exercises to prepare for the "BaPsy-DGPs", a German "Studieneignungstest für Psychologie".

This is neither official, nor in any way endorsed by the "Deutsche Gesellschaft für Psychologie e.V. (DGPs)", the "TransMIT Gesellschaft für Technologietransfer mbH" or anything related to the Studieneignungstest.

## Description

Dieses Projekt stellt Übungsaufgaben mit Erklärungen und Lösungen zur Verfügung, die für den [Studieneignungstest für Psychologie](https://studieneignungstest-psychologie.de) vorbereiten sollen.

Beachten Sie, dass dieses Projekt in keiner Weise mit dem offiziellen Test assoziiert ist und keinerlei Anspruch auf Vollständigkeit oder Aktualität hat. Zum Beispiel orientieren sich die Übungen zu figuralem, schlussfolgernden Denken an üblichen Rätselbüchern, während der offizielle Test abweichende oder zusätzliche Regeln verwenden kann oder in Zukunft interessante Sudoku-Varianten abfragt. Es wird empfohlen, dieses Projekt als zusätzliche Übung zu nutzen und mit den [offiziellen Trainingsmaterialien](https://www.studieneignungstest-psychologie.de/vorbereitung/#trainingsmaterialien) abzugleichen.
